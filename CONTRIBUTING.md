# Contributing

Thanks for taking an interest. This is a small project at **Public Beta 1**, so the most useful help right now is **testing and bug reports**.

## Reporting a problem
Open an issue and pick **Bug report**. The form asks for what is needed:
- which board and which release you used,
- what you did and what you expected,
- the lines from the Serial Monitor (115200 baud). For AIM problems, include the lines that start with DIR.

## Suggesting a device to detect
Use **Feature request**. Please describe how the device announces itself (its Wi-Fi network name or Bluetooth name, and its address prefix) and how you know. Do not post other people's private information.

## Code changes
Pull requests are welcome. Please keep each one small and focused, build it for the board it touches (see `devices/<board>/docs/BUILDING.md`) and describe how you tested it. `devices/<board>/docs/CODE_MAP.md` shows where each part of the firmware lives. By contributing you agree that your contribution is released under the same licence as the project (GPL v3).

## Responsible use
This project is for defensive, privacy-protecting use. Suggestions that aim to identify or track individual people will not be accepted.
