# Security

HUNTR/SEEKR is a passive listener. It does not transmit attacks, and it does not connect to other people's networks.

It does run a small web page on its own Wi-Fi hotspot (WPA2, random password) so you can use it from a phone. If you find a security problem in that page or in the update path, please use GitHub's **Report a vulnerability** option (Security tab > Advisories) rather than a public issue, so it can be fixed before details are shared.

This is a beta. Do not rely on it for safety-critical decisions.
